Overview

A Ractor::TMVar staged alongside TVars and Farce participants.

Take, put, and swap operate on the value staged in this attempt. An empty read, take, or swap, or a put into a full TMVar fails the attempt. Farce.transaction retries these conditions within its retry limit. The try_* methods return nil or false without failing the attempt. Assigned values are made shareable, matching Ractor::TVar's setter.

Run outside Ractor.atomically, as required by RactorTVar. Calls from other Ractors require Ractor-safe TVar methods from ractor-sharing.

Examples:

Transfer from a TMVar to an Atom

pending  = Ractor::TMVar.new(10)
received = Farce::Strict::Atom.new(0)
Farce.transaction do |tx|
  tx[received].value += tx[pending].take
end

def initialize(transaction, object)
  super
  # TMVar exposes no accessor for its storage. Reuse the TVar wrapper
  # so explicit enrollment of that same TVar shares all staged changes.
  compose(tvar: object.instance_variable_get(:@tvar))
end
