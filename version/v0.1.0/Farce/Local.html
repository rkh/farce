Overview

Shareable containers whose mutable contents belong to the current scope. Scopes may be :ractor, :thread_group, :thread, :fiber_storage, or :fiber. Initial contents are copied between Ractors. Within a Ractor, each scope has its own container, but objects supplied as initial contents may be shared.

Class Method Details

.enfarce(object, freeze: nil, scope: :ractor) {|object| ... } ⇒ BasicObject

Converts vanilla Ruby objects into their Farce::Local equivalents.

Valid scopes are:

  • :ractor - The value is shared by all threads within the same Ractor.
  • :thread_group - The value is shared by all threads within the same thread group.
  • :thread - The value is shared by all fibers within the same thread.
  • :fiber_storage - The value is shared by all fibers using the same storage. Unless explicitly specified, storage is inherited from the parent fiber for blocking fibers, but not for non-blocking fibers (such as those created by Scheduler#schedule).
  • :fiber - Each fiber has its own independent value.

Examples:

Farce::Local.enfarce({ foo: ["bar"] })
# =>  #<Farce::Local::Map {foo: #<Farce::Local::Vector ["bar"]>}>

Parameters:

  • object (BasicObject) —

    The root object to convert

  • freeze (Boolean, nil) (defaults to: nil) —

    Whether to freeze the converted objects. If set to nil (default), the freezing behavior will depend on the original object's frozen state.

  • scope (Symbol) (defaults to: :ractor) —

    The scope for the local container, e.g., :ractor.
