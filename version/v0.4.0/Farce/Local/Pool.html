Overview

A shareable handle with an independent thread pool in each scope.

Each pool uses the scaling settings and fiber scheduler configured at construction. Tasks always keep their block and argument references. Only local and smart modes are accepted when auto_local is false. A scheduler constructor must be convertible to a shareable proc for use in each Ractor. #close drains only the current scope's pool. #close_all drains every pool across all scopes and Ractors, and prevents new pools from starting.

Examples:

Keep task state within each Ractor

pool    = Farce::Local::Pool.new(max_size: 2)
results = Farce::Unshared::Queue.new
pool.schedule { results.push(:done) }
results.pop # => :done
pool.close_all

#initialize(min_size: 0, max_size: 4, max_inflight: 64, grow_after: 0.005, shrink_after: 30, capacity: 1024, scope: :ractor, backend: Internal::FROZEN_CONFIG.io_backend, &constructor) ⇒ BasicObject

Create and start an elastic pool using the configured fiber scheduler. An explicit constructor block overrides the configured default.

max_inflight is a soft limit. A worker may exceed it when its scheduler has no runnable fibers or when the pool has reached max_size.

Valid scopes are:

  • :ractor - The value is shared by all threads within the same Ractor.
  • :thread_group - The value is shared by all threads within the same thread group.
  • :thread - The value is shared by all fibers within the same thread.
  • :fiber_storage - The value is shared by all fibers using the same storage. Unless explicitly specified, storage is inherited from the parent fiber for blocking fibers, but not for non-blocking fibers (such as those created by Scheduler#schedule).
  • :fiber - Each fiber has its own independent value.

Parameters:

    Workers started immediately and retained while open.

    Maximum workers allowed.

  • max_inflight (Integer, nil) (defaults to: 64) —

    Soft task limit for each worker.

  • grow_after (Numeric) (defaults to: 0.005) —

    Queue wait before adding another worker.

  • shrink_after (Numeric, nil) (defaults to: 30) —

    Idle time before an extra worker retires.

  • capacity (Integer, nil) (defaults to: 1024) —

    Pending-task capacity.

  • backend (Symbol) (defaults to: Internal::FROZEN_CONFIG.io_backend) —

    IO backend for the built-in scheduler.

  • scope (Symbol) (defaults to: :ractor) —

    The scope of the pool. Defaults to :ractor.

def close_all
  return self unless @closed_all.compare_and_set(false, true)
  @pools.each_pair do |pool, queue|
    queue.push([pool, :close].freeze, clock: 0)
  rescue ClosedQueueError
    # The owning Ractor may already have shut down its supervisor.
    nil
  end
  close
end
