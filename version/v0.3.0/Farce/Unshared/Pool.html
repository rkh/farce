Overview

An elastic pool of thread workers within one Ractor.

Uses the same scaling and fiber schedulers as Pool. Tasks keep their blocks and argument references. auto_local: true ignores mode. With auto_local: false, only :local and smart modes are accepted. The pool cannot be copied or moved to another Ractor. A scheduler constructor may capture objects from this Ractor.

Examples:

Submit work using local state

results = Farce::Unshared::Queue.new
pool    = Farce::Unshared::Pool.new(max_size: 2)
pool.schedule { results.push(:done) }
results.pop # => :done
pool.close
