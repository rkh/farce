  • #subscribe(subscriber) ⇒ Subscription

    Adds a subscriber to the publisher. Register additional subscriber classes with Subscription.define. Publisher subscribers forward messages synchronously to their own subscribers. Avoid subscribing publishers in a cycle.

    Examples:

    Forward messages to another publisher

    upstream.subscribe(downstream)
upstream.publish(:message) # also publishes to downstream's subscribers

    Parameters:

    • subscriber (BasicObject) —

      The subscriber to add. Standard-library queues are supported by unshared and local publishers and retain the original payload. A full Thread::SizedQueue drops new messages. Publishing to a closed queue cancels its subscription.

      Calls one of the following methods:

      • Ractor#send
      • Ractor::Port#send
      • Queue#try_push
      • Thread::Queue#push
      • Thread::SizedQueue#push (nonblocking)
      • Counter#increment (without arguments)
      • Flag#set
      • Atom#value=
      • Set#<<
      • Vector#<<
      • Signal#broadcast (without arguments)
      • #publish
      • Concurrent::Event#set (without arguments)
      • Concurrent::CountDownLatch#count_down (without arguments)
      • Proc#call

      The concurrent-ruby integration supports these subscribers with unshared and local publishers:

      • Concurrent::AtomicReference#value=
      • Concurrent::AtomicFixnum#increment (without arguments)
      • Concurrent::AtomicBoolean#make_true
      • Concurrent::Event#set (without arguments)
      • Concurrent::CountDownLatch#count_down (without arguments)

      Set the default mode, auto_local, capacity, and similar options via initializers for these classes to influence how data transfer is handled.

      Support for additional subscribers can be added via Subscription.define.

  • #subscribe(*args, mode: nil, scheduler: nil, capacity: nil) {|*args, payload| ... } ⇒ Subscription

    Adds a subscription callback. Messages run in order on the selected scheduler. A full queue drops new messages. Unsubscribing drains queued messages and stops the callback.

    Examples:

    counter = Farce::Counter.new

publisher.subscribe(counter) do |counter, payload|
  counter.increment
  puts "Message ##{counter}: #{payload.inspect}"
end

    Parameters:

    • args (Array) —

      additional arguments to pass to the subscriber

    • mode (Symbol, nil) (defaults to: nil) —

      The transfer mode to use

    • scheduler (#schedule, nil) (defaults to: nil) —

      The scheduler to use for running the block

    • capacity (Integer, nil) (defaults to: nil) —

      the maximum queued messages, or nil for an unbounded queue

    Yields:

      the block to be called with the given arguments and payload

    Yield Parameters:

      the additional arguments passed to the block

def subscription_for(subscriber)
  if subscriber.is_a?(Subscription)
    return unless subscriber.publisher.equal?(self)
    subscription = map[subscriber.key]
    subscription if subscription.equal?(subscriber)
  else
    map[subscriber.__id__]
  end
end
