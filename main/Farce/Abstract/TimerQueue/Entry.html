Overview

A handle for canceling a scheduled value. Entries keep the stored value private, so canceling a moved value does not claim it. With local queues, cancellation uses the current scope.

Examples:

Cancel a delayed value

queue = Farce::TimerQueue.new
entry = queue.push(:work, delay: 60)
entry.delete # => true
