Overview

This class is abstract.

Common interface and behavior for atomic references.

Concrete implementations decide how values are retained and transferred. A value may become nil without an explicit update when an implementation retains it weakly.

Direct Known Subclasses

WeakAtom, Farce::Atom, Local::Atom, Strict::Atom
