#retire ⇒ self

Permanently retire this lease and wake its waiters.

The current Fiber must own the checkout. Retirement ends that checkout, so automatic block cleanup does not return the resource. The resource is not closed or otherwise disposed. Calling this again after retirement is safe.

Returns:

  • (self)

Raises:

  • (Farce::OwnershipError) —

    unless the current Fiber owns the checkout
