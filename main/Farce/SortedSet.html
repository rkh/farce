Overview

A Ractor-shareable concurrent set maintained in ascending order. Membership uses <=>. Comparator-equivalent elements occupy one slot. Transfer modes have the same behavior and restrictions as Farce::Set.

Examples:

Traverse priorities in order

priorities = Farce::SortedSet[30, 10, 20]
priorities.to_a # => [10, 20, 30]
