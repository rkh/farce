Overview

A Ractor-shareable atomic boolean for coordinating threads and Ractors. Only true and false are accepted. Read Abstract::Flag#value when testing the flag's state. Use Abstract::Flag#compare_and_set to check and change the state in a single atomic operation.

On CRuby, subclasses must not add Ruby instance variables.

Examples:

Allowing one caller to claim work

claimed = Farce::Flag.new
workers = 4.times.map do
  Thread.new { claimed.compare_and_set(false, true) }
end
workers.count { |worker| worker.value } # => 1
claimed.value # => true
