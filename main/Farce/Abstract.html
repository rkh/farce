Overview

Module holding abstract versions of classes that have multiple public implementations.

Subclasses of these can be found under the following namespaces:

  • Farce - for Ractor-shareable implementations
  • Local - implementations scoped by Ractor/Thread/Fiber/etc
  • Strict - for Ractor-shareable implementations accepting only shareable values
  • Unshared - for Ractor-unshareable implementations
  • Unsafe – for implementations that are not thread-safe
