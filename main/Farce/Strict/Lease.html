Overview

A Ractor-shareable lease that stores a shareable resource directly. Construction and checkin reject non-shareable resources without freezing them. Checkout coordinates callers. Other references remain usable, so callers must honor the checkout when accessing a mutable resource.

Examples:

Coordinating several changes to shareable state

lease = Farce::Strict::Lease.new { Farce::Strict::Map.new }
lease.checkout do |state|
  state[:status] = :ready
  state[:generation] = 1
end
lease.checkout { |state| state[:status] } # => :ready
