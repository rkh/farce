Overview

A shareable lazy value that retains its shareable result directly. The factory runs once, even when threads or Ractors access it concurrently. A failed factory or an unshareable result can be retried on the next access.

Examples:

Compute one shared snapshot

lazy = Farce::Strict::Lazy.new { [:ready].freeze }
lazy.value # => [:ready]
