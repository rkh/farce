Overview

A scheduler that starts a new thread for each scheduled task. Executes synchronous tasks inline. Creating an instance starts no threads. Blocks and arguments stay local to the caller. Tasks are not tracked, and closing this stateless scheduler has no effect. Default instances support Marshal. Instances with a custom thread factory reject dumping.

def schedule(*, **, &)
  raise LocalJumpError, "Cannot schedule without a block" unless block_given?
  @factory ? @factory.call(*, &) : Thread.new(*, &)
  self
end
