Overview

A thread-safe lazy value within one Ractor. Its factory may capture mutable state. The result retains its identity. Factory failures can be retried on the next access.

Examples:

Build a mutable cache on first access

lazy = Farce::Unshared::Lazy.new { {} }
lazy.value[:job] = :ready

class Lazy < Abstract::Lazy
  include Unshareable

  private

  def new_internal_atom = Internal::UnsharedAtom.new

  def prepare_proc(factory, **options)
    options.empty? ? factory : Farce.rebind(factory, **options)
  end
end
