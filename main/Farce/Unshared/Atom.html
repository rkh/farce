Overview

A thread-safe atomic reference that retains values directly within one Ractor. Mutable values keep their identity. Updates are serialized between threads.

Examples:

Updating an array atomically

atom = Farce::Unshared::Atom.new([])
atom.update { |items| items + [:job] }
