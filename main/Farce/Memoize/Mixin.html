Class Method Details

.new(*methods, scope: :global, mode: :smart, weak: false, visibility: nil) ⇒ Mixin

Creates or retrieves a memoization mixin for the given methods and options.

Parameters:

  • methods (Array<Symbol>) —

    The methods to memoize

  • scope (Symbol) (defaults to: :global) —

    The scope of the memoization. In addition to the normal scopes it may also be set to :global or :unshared.

  • mode (Symbol) (defaults to: :smart) —

    The mode of the memoization. Ignored for any scope other than :global. Defaults to :raise with weak: true, which supports only :raise, :make_shareable, and :dedup.

  • weak (Boolean) (defaults to: false) —

    Whether to use weak memoization. If enabled, memoized values may be garbage collected when no longer referenced. In this case, next access to the memoized method may recompute the value.

  • visibility (Symbol, nil) (defaults to: nil) —

    The visibility of the memoized methods. May be one of :public, :protected, or :private. If set to nil, Farce::Memoize#memoize will attempt to infer the visibility based on the context. Other methods will default to :public.

Returns:

  • (Mixin) —

    the memoization mixin

def self.new(*methods, **options)
  return super unless self == Mixin
  methods = Farce.dedup(methods.map(&:to_sym).uniq.sort)
  options = Farce.dedup(normalize_options(options))
  map     = KNOWN.store_if_absent(options) { Strict::Map.new }
  map.store_if_absent(methods) { super(methods, **options) }
end
