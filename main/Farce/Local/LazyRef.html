Overview

A Reference for a Local::Lazy value. Freezing affects the current scope's target. Afterward, frozen? reflects the current target and may initialize it when entering another scope.

Examples:

# Delegate to a Ractor-local hash
lazy_ref = Farce::Local::LazyRef.new { {} }

lazy_ref[:key] = :value
lazy_ref[:key] # => :value

Ractor.new(lazy_ref) do |lazy_ref|
  lazy_ref[:key] # => nil
end
