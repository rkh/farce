Overview

A shareable handle with an independent task scheduler in each scope.

new leaves each scheduler unstarted. Launch it with Abstract::Scheduler#launch_thread, or install it with Fiber.set_scheduler. Scheduler.create starts a worker thread in each scope when that scope is first used. The default scope is :ractor.

Tasks retain their blocks and argument references. Abstract::Executor#execute runs directly in the calling fiber. A fiber scheduler constructor must be convertible to a shareable proc for use in each Ractor. #close closes the current scope. #close_all closes all scopes and prevents new schedulers from starting. Scheduler.current returns an Unshared::Scheduler.

Examples:

Start one worker in each Ractor

scheduler = Farce::Local::Scheduler.create
results = Farce::Unshared::Queue.new
scheduler.schedule { results.push(:done) }
results.pop # => :done
scheduler.close_all

#initialize(capacity: 1024, backend: Farce.config.io_backend, scope: :ractor, &constructor) ⇒ Scheduler

Creates a handle whose scoped schedulers remain unstarted. The constructor block builds the fiber scheduler when a scope is launched or installed. Valid scopes are:

  • :ractor - The value is shared by all threads within the same Ractor.
  • :thread_group - The value is shared by all threads within the same thread group.
  • :thread - The value is shared by all fibers within the same thread.
  • :fiber_storage - The value is shared by all fibers using the same storage. Unless explicitly specified, storage is inherited from the parent fiber for blocking fibers, but not for non-blocking fibers (such as those created by #schedule).
  • :fiber - Each fiber has its own independent value.

Parameters:

  • capacity (Integer, nil) (defaults to: 1024) —

    Pending-task capacity, or nil for an unbounded queue in each scope.

  • backend (Symbol) (defaults to: Farce.config.io_backend) —

    IO backend for the built-in scheduler.

  • scope (Symbol) (defaults to: :ractor) —

    The scheduler scope. Defaults to :ractor.

Yield Returns:

  • (Object) —

    Fiber scheduler to install in each scope.

def initialize(capacity: 1024, backend: Internal::FROZEN_CONFIG.io_backend, scope: :ractor,
               worker: nil, &constructor)
  @constructor        = prepare_constructor(constructor || Internal::FROZEN_CONFIG.fiber_scheduler_constructor)
  @capacity           = capacity && Integer(capacity)
  @backend            = backend
  @worker             = worker
  @schedulers         = Strict::Map.new
  @closed_all         = Internal::Flag.new(false)
  @initialization_key = Object.new.freeze
  @registration_key   = Object.new.freeze
  super(scope:, capacity: capacity && Integer(capacity), backend:)
end

def self.create(executor = Thread, name: nil, priority: nil, **, &)
  raise ArgumentError, "Local schedulers cannot launch Ractor workers" if executor && executor <= Ractor
  worker = [executor || Thread, name && -String(name), priority && Integer(priority)].freeze
  new(**, worker:, &)
end

def close_all
  return self unless @closed_all.compare_and_set(false, true)
  @schedulers.each_pair do |scheduler, queue|
    queue.push([scheduler, :close].freeze, clock: 0)
  rescue ClosedQueueError
    # The owning Ractor may already have shut down its supervisor.
    nil
  end
  close
end

def launch(executor = Thread, name: nil, priority: nil)
  raise ArgumentError, "Local schedulers cannot launch Ractor workers" if executor && executor <= Ractor
  raise "Scheduler may not be reused" if @closed_all.value
  active_scoped_value.launch(executor, name:, priority:)
end

#try_schedule(*args, mode: :smart, auto_local: true) ⇒ self?
