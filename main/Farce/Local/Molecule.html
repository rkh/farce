Overview

A shareable record with independent field values in each selected scope. Use Abstract::Molecule.define to declare named fields. Explicitly supplied atoms keep their own storage and comparison policies.

Constructor Details

#initialize(scope: self.class.default_scope) ⇒ Molecule

Initialize fields using this variant's atoms. Valid scopes are:

  • :ractor - The value is shared by all threads within the same Ractor.
  • :thread_group - The value is shared by all threads within the same thread group.
  • :thread - The value is shared by all fibers within the same thread.
  • :fiber_storage - The value is shared by all fibers using the same storage. Unless explicitly specified, storage is inherited from the parent fiber for blocking fibers, but not for non-blocking fibers (such as those created by Scheduler#schedule).
  • :fiber - Each fiber has its own independent value.

Parameters:

  • scope (Symbol) (defaults to: self.class.default_scope) —

    the scope for new field atoms, defaulting to the record class scope

def self.define(*fields, scope: nil, **)
  unless scope.nil? || Internal::Storage::SCOPES.include?(scope)
    raise ArgumentError, "Invalid scope: #{scope.inspect}"
  end

  subclass = super(*fields, **)
  subclass.class_eval "def self.default_scope = #{scope.inspect}", __FILE__, __LINE__ unless scope.nil?
  subclass
end
